Import from CSV File

Upload a CSV file containing your social media content.

The CSV file should have the following columns:

  • publish_date: Date to publish (YYYY-MM-DD)
  • platform: Platform to publish to (twitter, linkedin, substack)
  • content: The content to publish
  • title: Title (required for Substack)
  • subtitle: Subtitle (optional, for Substack)
  • url: URL to share (optional, for LinkedIn)

Import from Google Sheets

Import content from a Google Sheet.

The Google Sheet should have the following columns:

  • publish_date: Date to publish (YYYY-MM-DD)
  • platform: Platform to publish to (twitter, linkedin, substack)
  • content: The content to publish
  • title: Title (required for Substack)
  • subtitle: Subtitle (optional, for Substack)
  • url: URL to share (optional, for LinkedIn)
